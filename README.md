
# IT Support Java Practice

## Project Description
This project is a simple Java program created for
UTS 43030 Professional Learning.

## Learning Objectives
- Practise Java programming
- Learn GitHub version control
- Understand Git commits
- Improve technical documentation
- Develop basic IT troubleshooting skills

## Project Features
The program simulates a simple IT support
system check.

It can:
- Display system information
- Check a simulated network connection
- Show the network connection status

## Tools Used
- Java
- GitHub
- Git version control

I plan to add more functions and improve
